«Звёздочка, лови улыбку!» — собранная версия проекта.

Открой index.html в браузере или загрузи всю папку zvezdochka_complete на статический хостинг (например, GitHub Pages / Netlify). Для работы все файлы из assets должны оставаться рядом с index.html.

Важно: для «Моих открытий» пока сделана система разблокировки девяти открытий и сохранения прогресса в браузере, но нарезка на 3×3 фрагмента большой фотографии не подключена: в предыдущей сборке была использована не та фотография. Чтобы не подменять её чужим/неверным снимком, нужно добавить правильное фото и после этого сделать реальные 9 фрагментов. Фото к вопросам фильма и секретной концовке использованы из имеющихся файлов и их соответствие нужно визуально перепроверить.
